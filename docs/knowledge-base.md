# База Знаний Agent Manager

База Знаний хранит архитектурные правила, описания проектов, системные промпты агентов и общую проектную документацию.

- **Физический путь в продакшн**: `~/.local/share/agent-manager/knowledge`
- **Версионирование**: База знаний инициализируется как отдельный Git-репозиторий. При каждом изменении документов через инструменты Секретаря или скрипты система автоматически создает git commit.

---

## 1. Структура каталогов

```
knowledge/
├── projects/              # Саммари и контекст поддерживаемых проектов
│   └── agent-manager/
│       └── summary.md     # Описание проекта, стек, порты, соглашения
├── components/            # Архитектурные правила по компонентам
│   ├── aiogram/
│   │   └── rules.md       # Версии, router-based подход, middleware
│   └── bubblewrap/
│       └── rules.md       # Правила песочницы pi-runner
├── agents/                # Профили агентов в формате Markdown + Frontmatter
│   ├── system-secretary.md
│   ├── system-code-reviewer.md
│   └── agent-manager-developer.md
└── docs/                  # Общая техническая документация
```

---

## 2. Горячая перезагрузка промптов (Hot-Reload)

1. **Редактирование на диске**:
   Файлы в `knowledge/agents/*.md` можно редактировать напрямую в редакторе или через бота.
2. **Синхронизация с БД**:
   Перед запуском раунда Code Review (`_run_review_cycle`) воркер проверяет наличие изменений в `knowledge/agents/system-code-reviewer.md` и автоматически обновляет ревизию в базе данных (`AgentProfileRepository`).
3. **Иммутабельность ревизий**:
   Все версии промптов и конфигураций сохраняются в таблице `agent_profiles` с автоинкрементным номером ревизии.
